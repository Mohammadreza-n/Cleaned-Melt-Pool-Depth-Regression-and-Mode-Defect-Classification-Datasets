This repository contains extensively cleaned data related to melt pool depth  regression and melt pool modes and defects classification used in our paper (currently under submission) titled 'Interpretable 1D Convolutional Neural Network Modeling in Metal Additive Manufacturing.' The data cleaning process is described in the appendix of our paper. The raw data are from various sources in the literature and compiled by the work cited as reference 8 in our article.



8.	Akbari, P. et al. MeltpoolNet: Melt pool characteristic prediction in Metal Additive Manufacturing using machine learning. Addit Manuf 55, (2022).
