This repository contains extensively cleaned data related to melt pool depth and melt pool modes and defects classification used in our paper (currently under submission) titled 'Physically Interpretable Convolutional Neural Network Modeling in Metal Additive Manufacturing.' The data cleaning process is described in the appendix of our paper. The raw data are from various sources in the literature and compiled by the work cited as reference [29] in our article.



[29]	P. Akbari, F. Ogoke, N.-Y. Kao, K. Meidani, C.-Y. Yeh, W. Lee, and A. B. Farimani, Additive Manufacturing 55, 102817 (2022).
