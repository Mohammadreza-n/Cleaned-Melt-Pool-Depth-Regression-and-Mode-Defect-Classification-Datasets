This repository contains extensively cleaned data related to melt pool depth  regression and melt pool modes and defects classification used in our paper (currently under submission) titled 'Physically Interpretable Convolutional Neural Network Modeling in Metal Additive Manufacturing.' The data cleaning process is described in the appendix of our paper. The raw data are from various sources in the literature and compiled by the work cited as reference [8] in our article.



8. 	Akbari P, Ogoke F, Kao NY, et al (2022) MeltpoolNet: Melt pool characteristic prediction in Metal Additive Manufacturing using machine learning. Addit Manuf 55:. https://doi.org/10.1016/j.addma.2022.102817
